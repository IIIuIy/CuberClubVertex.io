# Vertex-Hub - Киберспортивный клуб

Полноценный многостраничный сайт киберспортивного клуба с системой аутентификации и бронирования.

## 📁 Структура проекта

```
├── index.html          - Главная страница с регистрацией
├── profile.html        - Личный кабинет пользователя
├── admin.html          - Админ-панель (только для администратора) ⭐
├── about.html          - О клубе
├── tournaments.html    - Турниры
├── rental.html         - Аренда компьютеров
├── contacts.html       - Контакты
├── rules.html          - Правила сервиса
├── auth.js             - Система аутентификации
└── modal.js            - Управление модальными окнами
```

## 🚀 Как использовать

1. Откройте `index.html` в браузере
2. Зарегистрируйтесь (все данные сохраняются в localStorage)
3. Войдите в систему
4. Доступен личный кабинет с бронированием ПК

### Вход как администратор:
1. Зарегистрируйте аккаунт с логином `qwerty`
2. Войдите в личный кабинет
3. Нажмите "👑 Админ-панель" в меню
4. Введите админ-пароль: `vertex2026admin`
5. Получите доступ к полной панели управления

## ✨ Основные возможности

### 🔐 Система аутентификации
- **Регистрация** с валидацией:
  - Имя: 3-12 символов
  - Логин: 3-12 символов (латиница, цифры, подчеркивание)
  - Email: валидация формата
  - Пароль: минимум 8 символов
- **Вход** по логину и паролю
- **Сохранение профилей** в localStorage
- **Проверка уникальности** логина и email

### 👤 Личный кабинет
- **Бронирование компьютеров**:
  - Выбор тарифа (Стандарт/Премиум/VIP)
  - Выбор даты и времени
  - Количество часов (1-10+)
  - Количество ПК (1-5)
  - Количество человек
  - Автоматический расчет стоимости со скидками
- **Мои бронирования** - список всех бронирований
- **Статистика** - общая информация о посещениях
- **Настройки** - просмотр данных профиля
- **Кнопка "Выйти"** - выход из аккаунта

### 👑 Админ-панель (только для администратора)
- **Доступ**: только для аккаунта `qwerty` с админ-паролем
- **Админ-пароль**: `vertex2026admin`
- **Возможности**:
  - Просмотр всех пользователей
  - Просмотр всех бронирований
  - Статистика по клубу (пользователи, бронирования, выручка)
  - Отмена любых бронирований
  - Полная информация о системе
- **Визуальные отличия**: 
  - Корона 👑 рядом с логином администратора
  - Золотой интерфейс админ-панели
  - Пункт "Админ-панель" в меню личного кабинета

## 💾 Хранение данных

Все данные сохраняются в localStorage браузера:
- `users` - массив пользователей
- `currentUser` - текущий авторизованный пользователь
- `userBookings` - все бронирования

## 🔄 Дополнительные функции

- **Автоматический расчет скидок**:
  - 5 часов = скидка 20%
  - 10+ часов = скидка 25%
- **Валидация форм** в реальном времени
- **Защита страниц** - личный кабинет доступен только авторизованным
- **Статус бронирований** - активные/отмененные
- **История действий** - дата создания, статистика

## 📝 Примечания

- Пароли хранятся в открытом виде (для демо). В продакшене используйте хеширование!
- Данные хранятся локально в браузере
- Для сброса всех данных: откройте консоль и выполните `localStorage.clear()`
